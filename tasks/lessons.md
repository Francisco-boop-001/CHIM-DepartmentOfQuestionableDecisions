# Working rules

- Keep the interface companion-only. Do not replace AIAgent.dll or modify CHIM core to obtain an integration route.
- Assign product implementation to the requested GPT-6-LUNA/max workers. The coordinator owns independent review, verification, Git integration and publication.
- A missing or changed pinned owner identity must refuse access. It must never select an older path with weaker restore fencing.
- A case specification, source-shaped check or fake database test is not actual PostgreSQL evidence. Record those boundaries separately and preserve failed runs.
- A new compatibility release does not certify Skyrim input, audio, delivery, transfers or broad coexistence. Preserve the original Private Conversation fallback.
- Exercise the actual launcher and source-path mapping in host preflight. Preserve JSON timestamps as strings in every launcher/recovery reader; test equivalent Z and numeric-offset instants. Checking hashes or parsing syntax alone does not exercise those comparisons.
- Check distro state before every WSL execution after cleanup: even a read-only process query can cold-start a stopped distro. Use host-side status receipts and inventory first, then record any probe-owned restart and its final stopped state.
- Do not call a context assertion from a callback that already holds the same state-file lock. Preflight before entry, then rely on the fresh validation performed under that lock immediately before commit.

- Establish fixture preconditions through the pinned owner's real contract and assert their receipts before measuring dependent behavior. Preserve helper stdout/stderr on failure; do not silently convert setup failures into apparently valid queued or empty results. Count attempted SQL separately from committed row changes and from same-ID retries.


- A nominally read-only owner helper may manage its own transaction. Trace its implementation before using it inside an existing snapshot; never construct an uninitialized owner store there. Form lookups must reuse the fenced connection without BEGIN/COMMIT/ROLLBACK, and positive receipt cases must assert that boundary in the SQL trace.

- Verify a checksum manifest with its ordinary external consumer. Parsing lines and comparing hashes can miss CRLF filenames; generate explicit LF bytes independent of the host platform.
- A historical source snapshot must be labeled and point to the authoritative Git repository. Use named worktrees for changes, keep release tags immutable, and fast-forward a clean primary checkout after publication.

- Before releasing an owner version used by an exact-pinned companion, execute the companion's readiness/pairing probe against the exact candidate sources and record the supported pairing. A source hash addition alone does not validate lifecycle or document-contract changes.

- Check newly added files after explicit staging: ordinary git diff --check omits untracked content. Preserve established line endings and reject extra blank EOF lines before recording final source hashes.
- Evidence examples must write UTF-8 without BOM explicitly on Windows. Shell redirection defaults are not a portable JSON or checksum encoding contract.

- A versioned harness may still call unchanged shared probes at their original filenames. Resolve every literal test path against the frozen tree before TEST and compare ordered case IDs, not counts alone.

- Tests that remove shared fixture tables must restore their exact rows in cleanup. Positive compose tests must explicitly establish fresh owner presence before measurement; never count queued as dispatched or hide fixture writes in API helpers. Keep SQL boolean projection consistent with strict callers.

- Derive concurrency barriers and rendering preconditions from pinned owner calls and raw SQL/GD evidence. A pending marker can precede a queued shared ingress lock; do not wait for a later exclusive stage through the owner timeout. Character count is not image-layout capacity. Never alter stock assets, relax receipt/privacy checks, or use contrived skinny text to manufacture a passing delivery claim.

- Keep success and refusal transaction oracles separate. A known not_found exception inside a fenced read snapshot must roll back exactly once and unlock; successful reads and receipt reconciliation must commit exactly once without rollback. Trace the actual exception boundary before reusing a helper.

- Check new SQL against the pinned migration, including JSON-only fields. Keep client idempotency/request IDs separate from owner-generated operation UUIDs; verify links through the real document and operations row instead of equating independent identifiers.

Preserve UTF-8 and existing per-file line endings during documentation edits. Scan changed prose for mojibake before freezing. In a byte-preserving repository, run Git whitespace checks with cr-at-eol rather than normalizing executed or frozen CRLF inputs; ordinary trailing spaces still fail.

- Before reusing a test, inspect its loops and platform prerequisites. Run only changed-boundary checks; retention/load suites need a specific changed dependency to justify them. Enable the actual Unicode extension for Unicode fixtures, and keep stopped or prerequisite-failed runs separate from passing evidence.

- A downloadable game mod is not install-and-use when it still requires Linux CLI provisioning, web-worker environment edits, or hand-copied tokens. Verify the actual fresh-user install and connection path before handing off Skyrim functional tests; expose missing configuration distinctly from rejected authentication and preserve the real error in the UI.
- Ordinary install-and-use must not be redefined as manual browser pairing when the user expects existing CHIM mod integration. Establish the required trust boundary and supported automatic route before adding a separate approval workflow. For browser forms, test an actual navigation/form POST with the production response headers; manually supplied Origin/cookie headers cannot verify browser-generated behavior.

- A compatible source/version matrix does not prove that the installed in-game bridge initializes or authenticates. State that boundary when answering compatibility questions; investigate actual local startup before attributing every disabled tab to its owner plugin.
