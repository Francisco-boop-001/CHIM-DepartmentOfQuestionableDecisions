# Working rules

- Keep the interface companion-only. Do not replace AIAgent.dll or modify CHIM core to obtain an integration route.
- Assign product implementation to the requested GPT-6-LUNA/max workers. The coordinator owns independent review, verification, Git integration and publication.
- A missing or changed pinned owner identity must refuse access. It must never select an older path with weaker restore fencing.
- A case specification, source-shaped check or fake database test is not actual PostgreSQL evidence. Record those boundaries separately and preserve failed runs.
- A new compatibility release does not certify Skyrim input, audio, delivery, transfers or broad coexistence. Preserve the original Private Conversation fallback.
- Exercise the actual launcher and source-path mapping in host preflight. Preserve JSON timestamps as strings in every launcher/recovery reader; test equivalent Z and numeric-offset instants. Checking hashes or parsing syntax alone does not exercise those comparisons.
- Check distro state before every WSL execution after cleanup: even a read-only process query can cold-start a stopped distro. Use host-side status receipts and inventory first, then record any probe-owned restart and its final stopped state.
- Do not call a context assertion from a callback that already holds the same state-file lock. Preflight before entry, then rely on the fresh validation performed under that lock immediately before commit.

- Establish fixture preconditions through the pinned owner's real contract and assert their receipts before measuring dependent behavior. Preserve helper stdout/stderr on failure; do not silently convert setup failures into apparently valid queued or empty results. Count attempted SQL separately from committed row changes and from same-ID retries.


- A nominally read-only owner helper may manage its own transaction. Trace its implementation before using it inside an existing snapshot; never construct an uninitialized owner store there. Form lookups must reuse the fenced connection without BEGIN/COMMIT/ROLLBACK, and positive receipt cases must assert that boundary in the SQL trace.

- Verify a checksum manifest with its ordinary external consumer. Parsing lines and comparing hashes can miss CRLF filenames; generate explicit LF bytes independent of the host platform.
- A historical source snapshot must be labeled and point to the authoritative Git repository. Use named worktrees for changes, keep release tags immutable, and fast-forward a clean primary checkout after publication.
