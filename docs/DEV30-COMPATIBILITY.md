# Sealed Fates dev.30 compatibility

Prealpha.26 targets the exact Sealed Fates dev.30 owner at commit `1eb58d999698002f8aeaa05b21464f7608717794`. Its adapter pins the frozen 20-file closure from the owner binding. Three pins differ from dev.29: `manifest.json`, `lib/runtime.php`, and `lib/companion.php`; the other 17 closure hashes remain unchanged. The Department DWPkg changes only its two version manifests, `server/adapters/correspondence.php`, and regenerated `checksums.sha256`. The package starts from the published prealpha.25 ZIP and preserves its other 21 MO2 payloads byte-for-byte, including PCV companion 0.1.0-prealpha.12 and the PCV 0.1.24 closure. PCV 0.1.25 is outside this pairing and requires a separate compatibility update.

## Required TEST2 evidence

The prealpha.26 builder requires `actual-pg-result.json` and `actual-pg-shutdown.json` for the same frozen source commit and exact dev.30 owner. The passing result must identify `DwemerAI4Skyrim3-test2`, a private network namespace, PostgreSQL 15, and private loopback-only TCP. The pinned core client uses `localhost:5432`, so the test cluster listens at `127.0.0.1:5432` in a fresh Linux network namespace with only the loopback interface enabled and no external/default route. The result must record `socketOnly: false` and `privateLoopbackOnly: true`; Unix-socket-only access is not used for this run. It binds the candidate adapter and every fixed test/helper input by source hash, records the ordered passing test cases and matching counts, and limits its claim to database checks. The data directory must have the exact run-scoped `/var/tmp/department-dev23-<runId>/postgres/data` shape and the socket directory its `/var/tmp/department-dev23-<runId>/socket` sibling. The builder checks that lexical shape and sibling relationship; the fixture checks canonical paths and rejects links. The shutdown receipt must match the tested database identity and source commit, record the owned process as stopped, and confirm the scratch database was removed.

The generated `-test-proof.zip` contains the canonical safe `test-proof.json` summary and generated package provenance. It records the owner closure, source and receipt hashes, PostgreSQL version, test-distro and namespace status, `privateLoopbackOnly: true`, `socketOnly: false`, the listener address, the `networkEvidenceSha256` digest, case identifiers, counts, and limits. The digest binds the private source-load trace containing raw topology routes and parent/child namespace IDs; the trace itself remains outside the package. The proof omits database identity paths, role, system identifier, port, process ID, raw route data, namespace IDs, raw logs, database files, and user data.

This evidence covers direct Department adapter/service behavior against PostgreSQL in isolated TEST2 over private TCP loopback. It does not establish HTTP bootstrap or endpoint behavior, model/provider behavior, native delivery, physical transfer, installed-game compatibility, live-server behavior, or Skyrim gameplay. The unchanged native payload is retained from prealpha.25; this package update does not rebuild or revalidate it. Historical dev.29 evidence remains evidence for dev.29 only.
