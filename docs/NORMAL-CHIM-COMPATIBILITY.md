# Normal CHIM compatibility — prealpha.23

Prealpha.23 supports ordinary CHIM mode with Playthrough Saves disabled. That mode uses CHIM's existing shared history. History is shared host state, not per-save isolation. The Department must not synthesize a profile/save UUID, remap existing rows, or migrate shared history to a managed profile.

Existing managed profiles keep the current strict identity checks and per-profile isolation, including the established refusal and rollback behavior for pending, ambiguous, or malformed profile state. The normal-mode path must not weaken those checks.
