# Disposable profile endpoint setup

This companion requires an isolated Skyrim/MO2 profile, disposable save and separate test CHIM installation/database. A separate save does not isolate a server database. Never change the shared/live AIAgent.ini or point a live game at an experimental server.

1. Duplicate/create a dedicated MO2 test profile. Install the supported complete CHIM and four owner plugin releases and their documented game components there. Keep the Department mod disabled in the live profile.
2. In the test profile, identify the effective provider of SKSE/Plugins/AIAgent.ini. Create an empty MO2 mod named Department Test Endpoint, enabled only in this test profile, and copy that INI into its SKSE/Plugins directory. This is a test-profile override; do not edit the original provider file. Ensure this override wins only in the test profile. Do not include the INI in a public release or screenshot if it contains private settings.
3. In that override, use SERVER=127.0.0.1, the isolated test server's PORT, and its exact PATH ending in /HerikaServer/comm.php. Do not assume that a particular port or installation path identifies the test server. Verify the test server/database identity before connecting. Leave the live server untouched.
4. Set the test profile's SKSE/Plugins/WorldOfDramaLlama.ini BaseUrl to the same literal HTTP IPv4 loopback host, port and base path, without comm.php or api.php. Set PairToken only to a new token provisioned for that test server/profile. Empty shipping configuration is intentional. The stock CHIM destination and companion facade destination must match exactly.
5. Restart Skyrim completely after any endpoint change: CHIM caches its startup destination. Check that WSL2 localhost forwarding reaches the isolated test server from Windows. Verify CHIM's ordinary, untagged streaming/input works through that same 127.0.0.1 endpoint before testing the Department textbox. A working facade alone is insufficient. If forwarding or ordinary streaming fails, fix the test-only forwarding/setup; do not broaden the companion's HTTP trust policy, change the shared/live INI, or redirect traffic to the live server.
6. Use CHIM Standard mode, allow normal background presence updates, then refresh the Department cast, select eligible actors, Arm and send one distinctive line. Test the original PCV page/input fallback with the Department mod disabled. An unknown operation must be reconciled, not blindly sent again.
7. Before returning to the live profile, quit Skyrim and disable/remove the test-only override there. Revoke the test pairing and clear its PairToken before sharing or retiring the test profile. Preserve the original CHIM provider files and verify they never changed.

Supported transport is currently plain HTTP to literal 127.0.0.1 for the private textbox. HTTPS or an arbitrary LAN/WSL address is not an equivalent supported private route. This guide describes how to make a safe profile-local setup; localhost forwarding, actual streaming, focus/controller behavior, NPC/audio delivery, transfers and save/load still require the user's game test.

PCV overlay maintenance: retain backups/base hashes. Reinstalling/updating Private Conversation may overwrite the three modified overlay files without changing its manifest version. Recheck the overlay postimage hashes before using the companion after an owner reinstall/update. Source drift must remain refused; never overwrite a newer owner version blindly.
