# Sealed Fates dev.25 compatibility

Published prealpha.17 pairs the Department server adapter with Sealed Fates dev.25 from source commit `a28cb8333582c59a92c25f67f72073899cd0e63c`. The Department adapter includes a literal 19-file owner map: the manifest hash advances, while all 18 execution-file hashes remain exactly equal to the supported dev.24 map. The existing capability paths are reused; this update adds no new pairing behavior.

The package starts from the exact published prealpha.16 installable archive with SHA-256 `5de96da71a044496d8d9e767165ef460c82725e708ba7920b40eebcededb30c1`. Its installable may replace only the Department DWPkg. Within that package, the only allowed changes are the outer and server manifests, `server/adapters/correspondence.php`, and regenerated checksums. The other 21 MO2 members remain byte-identical, including the prealpha.16 DLL, UI, notices and companion packages. The original Private Conversation fallback and all existing owner pins are preserved.

The package build requires a compatibility receipt bound to one frozen Department source commit and the exact dev.25 pin map. The receipt records source-contract, dev.24 regression, pairing-readiness and protected-payload checks. These checks establish source/package pairing only; they do not establish dev.25 database behavior, HTTP/provider behavior, an actual CHIM-server run or Skyrim acceptance. See the [verification record](VERIFICATION.md) for the verified publication record.
